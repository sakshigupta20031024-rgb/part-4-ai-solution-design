# Task 8 — Final Solution Summary

## Problem

Banks need a faster and smarter way to detect suspicious financial transactions.

## Proposed AI Solution

An AI-based fraud detection system using neural networks and anomaly detection techniques.

## Required Data

- Transaction history
- Customer activity
- Device and location information

## Recommended Model

Feed-forward neural network or autoencoder model.

## Expected Business Impact

- Faster fraud detection
- Reduced financial losses
- Improved investigation efficiency
- Better customer security

## Risks and Mitigation

### Risk:
False positives blocking genuine users

### Mitigation:
Human review process before account restrictions are applied.
